# MuseTicket – Дипломный проект
Веб-платформа для онлайн-бронирования билетов в музей с поддержкой четырёх ролей: посетитель, кассир, администратор музея и генеральный директор.

## Функциональность
###Для посетителей
* Просмотр каталога музеев с фотогалереей, описанием и ценами
* Выбор даты и времени посещения с интерактивным календарём свободных слотов
* Гибкое формирование заказа: для каждого билета можно задать отдельную категорию (Стандартный, Льготный, Детский, Студенческий, Пенсионный)
* Применение промокода (купона) со скидкой на весь заказ
* Онлайн-оплата с защитой от перебронирования
* Получение электронного билета со штрих-кодом и QR-кодом
* Личный кабинет с историей покупок, сохранение билета в PNG и отправка по ссылке

###Для кассира
* Вход по коду музея и паролю
* Офлайн-продажа билетов: выбор слота, добавление нескольких билетов разных категорий, ввод данных посетителя
* Проверка билетов на входе (подтверждение или отказ с указанием причины)
* Просмотр истории проверенных билетов с возможностью возврата

###Для администратора музея
* Управление информацией о музее: название, описание, цена, изображения, режим работы
* Настройка закрытых дат и ручное управление временными слотами
* Создание и редактирование скидочных категорий билетов
* Статистика продаж с графиком и экспорт отчёта в PDF
* Поиск и редактирование купленных билетов

###Для генерального директора (суперадминистратора)
* Полный доступ ко всем музеям системы
* Создание и удаление музеев
* Управление учётными данными администраторов
* Глобальная настройка автоматической генерации временных слотов
* Управление купонами (промокодами) с лимитом и сроком действия

## Стек технологий
- **Backend:** Python, FastAPI, Pydantic
- **Frontend:** HTML, CSS, JavaScript (без фреймворков), Chart.js, html2canvas, jsPDF
- **База данных:** MySQL
- **Веб-сервер:** Uvicorn
- **Дополнительно:** WebSocket для мгновенных уведомлений

## Старт проекта
1) Клонирование репозитория
```bash
git clone https://github.com/nematovmark5-lgtm/Museum_ticket_sales.git
cd Museum_ticket_sales
```
2) Создание и активация venv
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate
```
3) Установка зависимостей
```bash
pip install -r requirements.txt
```
4) Загрузка базы данных
* Запустить скрипт из файла dumpTOPend.sql в MySQL Workbench
5) Запуск проекта
```bash
python server.py
```
Сервер стартует на порту 8002.
Swagger-документация будет доступна по адресу: http://localhost:8002/docs

6) Открытие клиентской части
* Главная страница для посетителей: http://localhost:8002/
* Интерфейс кассира: http://localhost:8002/kasir.html
* Панель администратора музея: http://localhost:8002/admin.html
* Панель суперадминистратора: http://localhost:8002/superadmin.html
